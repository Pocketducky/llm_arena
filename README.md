# Арена LLM — Полная инструкция по запуску

## Что делает система

```
Для каждой суммаризации:

  РАУНД 1 — Независимая оценка
  ────────────────────────────
  ЭМК + Суммаризация → qwen2.5:14b  → Отчёт A (балл + аргументация)
  ЭМК + Суммаризация → mistral      → Отчёт B (балл + аргументация)
  ЭМК + Суммаризация → llama-3.3-70b → Отчёт C (балл + аргументация)

  РАУНД 2 — Cross-peer review (отчёты перемешаны)
  ─────────────────────────────────────────────────
  ЭМК + Суммаризация + Отчёт B + Отчёт C → qwen2.5:14b  → Финал A
  ЭМК + Суммаризация + Отчёт A + Отчёт C → mistral      → Финал B
  ЭМК + Суммаризация + Отчёт A + Отчёт B → llama-3.3-70b → Финал C

  АГРЕГАЦИЯ
  ─────────
  Итоговый балл = среднее(0.7×R2 + 0.3×R1) по трём судьям
```

## Шаг 1 — Установить Homebrew (если не установлен)

Открой Terminal и выполни:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

---

## Шаг 2 — Установить Ollama

```bash
brew install ollama
```

Проверь установку:
```bash
ollama --version
```

---

## Шаг 3 — Запустить сервер Ollama

```bash
ollama serve
```

> Оставь этот терминал открытым. Ollama работает как фоновый сервер.
> Открой новую вкладку Terminal для следующих команд.

---

## Шаг 4 — Скачать модели

```bash
# Основная модель — русский + медицина (9 GB, ~10-15 мин скачивания)
ollama pull qwen2.5:14b

# Вторая модель (4.1 GB, ~5 мин)
ollama pull mistral

# Проверить что скачались
ollama list
```

> Скачивание нужно только один раз. Модели хранятся на диске.

---

## Шаг 5 — Получить бесплатный API ключ Groq

1. Перейди на https://console.groq.com
2. Зарегистрируйся (Google аккаунт достаточно)
3. Перейди в **API Keys** → **Create API Key**
4. Скопируй ключ (начинается с `gsk_...`)

> Карта не нужна. Лимит: 14,400 запросов/день — тебе хватит с запасом.

## Шаг 8 — Задать API ключ Groq

```bash

export GROQ_API_KEY=gsk_ВАШ_КЛЮЧ_ЗДЕСЬ

# Постоянно (добавить в ~/.zshrc)

source ~/.zshrc
```

## Шаг 11 — Запустить оценку

### Обычный запуск (видишь прогресс в терминале):
```bash
python evaluator.py
```

### Запуск в фоне на ночь (рекомендуется):
```bash
nohup python evaluator.py > evaluation.log 2>&1 &
echo "PID: $!"
```

Следить за прогрессом:
```bash
tail -f evaluation.log
```

Остановить если нужно:
```bash
kill $(cat evaluator.pid)
# или найди PID: ps aux | grep evaluator
```

## Решение типичных проблем

### "Ollama не запущен"
```bash
ollama serve
# Если порт занят:
lsof -ti:11434 | xargs kill -9
ollama serve
```

### "Модель не найдена"
```bash
ollama list          # посмотри что скачано
ollama pull qwen2.5:14b  # скачай заново
```

### "Groq rate limit (429)"
Скрипт автоматически ждёт и повторяет. Если проблема постоянная —
увеличь `GROQ_SLEEP = 20` в начале `evaluator.py`.

### "JSON не найден в ответе"
Модель ответила не в JSON формате. Скрипт логирует это и продолжает.
Проверь `evaluation.log` для деталей.

### Ноутбук нагревается
Это нормально при работе 14B модели. Убедись что вентиляция не заблокирована.
При желании можно ограничить нагрузку: в `evaluator.py` добавь `OLLAMA_SLEEP = 10`.

| Конфигурация | Время на 1 суммаризацию | 182 суммаризации |
|---|---|---|
| Только Ollama 14B (медленно) | ~5-6 мин | ~18 часов |

| Только Groq (быстро) | ~30 сек | ~2 часа |
